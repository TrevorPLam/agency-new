## Multi‑Tenancy

- **Tenant context** derived from authenticated JWT claims (`session.user.tenantId`).
- **Database isolation** via shared schema + Row‑Level Security (RLS). Every table with `tenant_id` has an RLS policy.
- **Tenant resolution:** Edge middleware attaches `tenantId` from the request. For Vercel this uses `proxy.ts`; for Cloudflare we temporarily use `middleware.ts`. The shared logic lives in `@firm/auth/middleware`. Full explanation: [Tenant Resolution](./core/tenant-resolution.md).
- **Theming** via CSS custom properties scoped to `data-theme` attribute.

## Observability

- Structured JSON logs (Pino) to stdout → scraped by Loki.
- Prometheus metrics on every service (`/metrics`). Required metrics: `http_requests_total`, `http_request_duration_seconds`, `db_queries_total`, `ai_tokens_used_total`.
- Health checks: `GET /api/health` must return 200 within 5 seconds (liveness, readiness, DB ping).
- Distributed tracing via OpenTelemetry (traces exported to Grafana Tempo).
- Dashboards as code in `grafana/dashboards/`.

## Security Baseline

- pnpm 11 hardened defaults: `minimumReleaseAge: 1440`, `blockExoticSubdeps: true`, explicit `allowBuilds`.
- All HTTP endpoints enforce CSP, HSTS, and other security headers generated by `firm-security`.
- Secrets managed in Infisical (self‑hosted). No hardcoded secrets.
- Multi‑tenant data access wrapped in `setTenantContext()` (sets `app.current_tenant_id` via `SET LOCAL`).
- Webhook signatures verified with constant‑time comparison.

## AI Stack

- **LLM Gateway:** `firm-ai-core` routes to Claude Opus 4.7, GPT-5, Gemini 3.1 Pro, and GPT-5 Nano depending on task.
- **Structured Output:** Vercel AI SDK `Output.json()` with Zod schemas.
- **Brand Voice:** Per‑client profiles stored in `firm-ai-brand-voice` with pgvector embeddings.
- **Compliance:** AI‑generated content is watermarked with C2PA manifests (EU AI Act Art. 50) and carries non‑removable disclosure labels.

## Self‑Hosted Services (Hetzner)

- **Control Plane:** Coolify manages all Docker services.
- **Identity Provider:** Authentik → `auth.[agency-domain].com`
- **Secrets:** Infisical → `secrets.[agency-domain].com` (IP‑restricted)
- **Monitoring:** Prometheus, Grafana, Loki → `vps-observability`
- **Analytics:** Umami → `umami.[agency-domain].com`
